# remind+

Ingat ujian, kejar deadline, kumpulkan poin, naik level.
Aplikasi web yang bisa dipasang di Android (PWA), dengan akun online yang tersinkron.

**Buka:** https://vanoofiahkahi.github.io/poin-mandiri/

**Aplikasi Android (dengan widget layar utama):** unduh `remindplus.apk` dari [Releases](https://github.com/vanoofiahkahi/poin-mandiri/releases/latest). APK dibuat otomatis oleh GitHub Actions dari folder `android/`.

## Fitur
- **Tugas** dengan tingkat kesulitan, deadline, dan poin
- **Ujian** dengan pengingat belajar malam sebelumnya
- **Jadwal pelajaran** yang diisi per tanggal
- **Kas** — pengingat bayar uang kas
- **Pengingat** sekolah, pribadi, dan acara sekolah
- **Timer belajar**, level, streak, dan riwayat poin
- Widget jadwal berikutnya, rencana belajar ujian, PR dari jadwal
- Ringkasan mingguan, pencapaian, pembeku streak, pelacak nilai (opsional)
- **Mode libur**, **hitung mundur**, dan **bagikan jadwal lewat QR code**
- Panduan untuk pengguna baru
- Alarm darurat, Bahasa Indonesia & English, mode terang/gelap, 6 warna aksen, liquid glass
